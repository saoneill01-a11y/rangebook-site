# rangebook.org

The website for [Range Book](https://github.com/saoneill01-a11y/rangebook). It's one plain HTML page (`index.html`) with its screenshots, fonts and icons, served by GitHub Pages at https://rangebook.org.

To change the page, edit `index.html` and push to `main`. GitHub Pages republishes it within a minute or two.

The fonts (Barlow Condensed, IBM Plex Sans, IBM Plex Mono) are under the SIL Open Font License; see `fonts/`.
